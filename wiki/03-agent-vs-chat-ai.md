# AI Agent 與一般聊天 AI 的差異

## 1. 一般聊天 AI

一般聊天 AI 主要透過對話方式回答使用者的問題，能夠協助解釋知識、翻譯文字、整理內容、提供建議及生成文章等。

使用者提出問題後，AI 通常會直接產生回覆，使用者可以根據回答繼續提問或調整需求。

## 2. AI Agent

AI Agent 著重於完成使用者指定的目標。除了理解需求與產生回覆之外，也可能具備規劃步驟、使用工具、執行任務及檢查結果等功能。

在具備相關能力與授權的情況下，AI Agent 可以協助處理多個步驟的工作。

## 3. 兩者的主要差異

| 比較項目 | 一般聊天 AI | AI Agent |
|---|---|---|
| 主要目的 | 回答問題、提供資訊 | 協助完成指定目標 |
| 使用方式 | 以對話互動為主 | 以任務執行為導向 |
| 工作流程 | 通常直接生成回覆 | 可能規劃並執行多個步驟 |
| 工具使用 | 依系統功能而定 | 可能整合工具協助執行 |
| 任務處理 | 使用者常需要自行安排後續 | 可依系統能力處理部分流程 |

## 4. 生活中的例子

如果使用者詢問「如何規劃一份讀書計畫」，一般聊天 AI 可以提供建議與讀書安排。

而 AI Agent 則可能在具備相關功能及權限時，進一步協助整理學習目標、安排每日進度、建立任務清單及追蹤完成狀況。

## 5. 兩者並非完全不同

一般聊天 AI 與 AI Agent 並不是完全分開的類型。現在有些聊天 AI 也具備搜尋、工具使用及多步驟處理功能，而 AI Agent 也可能透過對話與使用者互動。

因此，兩者的差異主要在於系統設計、任務目標、自主程度以及可使用的工具，而不是單純看它是否能聊天。

## 6. 小結

一般聊天 AI 主要提供對話及資訊協助，而 AI Agent 更著重於依照目標規劃與完成任務。兩者都具有實用價值，應依照不同需求選擇適合的工具。
