# AI Agent Workflow

## 1. 工作流程說明

AI Agent 會依照使用者的目標，進行分析、規劃、執行及結果檢查，並根據檢查結果決定是否需要重新調整。

## 2. Workflow 流程圖

    D --> E[執行任務]

    H --> I[回覆使用者]
    G -->|否| J[重新分析與調整]
    J --> C

## 3. 流程步驟

1. **輸入任務：** 使用者提出需求或目標。
2. **分析與規劃：** AI Agent 分析需求，拆解工作步驟。
3. **選擇工具：** 根據任務需要選擇適合的方法或工具。
4. **執行任務：** 依照規劃進行處理。
5. **檢查結果：** 確認結果是否符合使用者目標。
6. **調整流程：** 如果結果不理想，重新分析並調整執行方式。
7. **完成任務：** 整理結果並回覆使用者。

## 4. Workflow 設計目的

透過流程化設計，讓 AI Agent 的任務執行過程更加清楚，並藉由結果檢查與重新調整，降低錯誤並提升完成任務的品質。
